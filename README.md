Cara Run Project:

*Frontend*
1) cd frontend
2) npm init -y
3) npm install
4) npm start

*Backend*
1) cd backend
2) npm install
3) npm install cors
4) npm install express cors mysql2 dotenv
5) npm install bcrypt jsonwebtoken
6) npm install jsonwebtoken body-parser multer
7) npm install @supabase/supabase-js
8) node server.js
